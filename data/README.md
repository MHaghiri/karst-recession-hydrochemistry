# Data

Input data for *Linking Recession-Based Karst Development Classes to Hydrogeochemical and Isotopic Signatures in Dolomitic Hard-Rock Aquifers (Alborz, Iran)*.

Generated by `tidy_data.py` on 2026-10-22 from the original spreadsheets and GIS layers. All tables are UTF-8 CSV with a single header row; empty cells are missing values.

Sampling: discharge monthly at 15 sources (April-December 2025); hydrochemistry at 19 sources in May 2025 (wet) and November 2025 (dry); stable isotopes in May 2025.

## `hydrodynamics/discharge_monthly_wide.csv`

Monthly discharge (L/s), April-December 2025, at 11 springs (S1-S11) and 4 qanats (Q1-Q4); one row per source.

| Column | Description |
|---|---|
| `source_id` | Source code used in the paper (S = spring, Q = qanat, W = well) |
| `source_type` | spring, qanat or well |
| `source_name` | Local name of the spring or qanat |
| `Q_apr_Ls` | Discharge in Apr 2025 (L/s) |
| `Q_may_Ls` | Discharge in May 2025 (L/s) |
| `Q_jun_Ls` | Discharge in Jun 2025 (L/s) |
| `Q_jul_Ls` | Discharge in Jul 2025 (L/s) |
| `Q_aug_Ls` | Discharge in Aug 2025 (L/s) |
| `Q_sep_Ls` | Discharge in Sep 2025 (L/s) |
| `Q_oct_Ls` | Discharge in Oct 2025 (L/s) |

## `hydrochemistry/hydrochemistry.csv`

Field and laboratory hydrochemistry of 19 groundwater sources (springs S1-S11, qanats Q1-Q4, wells W1-W4) in the wet (May 2025) and dry (November 2025) seasons; one row per sample and season. Major ions Ca, Mg, Na, K, Cl, SO4, HCO3 are given in the units of the source workbook (see note below).

| Column | Description |
|---|---|
| `sample_id` | Sample code used in the paper (S = spring, Q = qanat, W = well) |
| `sample_name` | Local name of the sampled source |
| `source_type` | spring, qanat or well |
| `season` | wet (May 2025) or dry (November 2025) |
| `sampling_month` | Year-month of sampling |
| `Ca` | Calcium |
| `Mg` | Magnesium |
| `Na` | Sodium |
| `K` | Potassium |
| `Cl` | Chloride |
| `SO4` | Sulfate |
| `HCO3` | Bicarbonate |
| `EC_uS_cm` | Electrical conductivity (uS/cm) |
| `TDS_mg_L` | Total dissolved solids (mg/L) |
| `pH` | pH |
| `temp_C` | Water temperature (deg C) |

## Note on ion units

Major-ion values (Ca, Mg, Na, K, Cl, SO4, HCO3) are given exactly as in the source workbook. **Check and state the unit here (mg/L or meq/L) before making this repository public.**

## `gis/`

| Layer | Description | Original file |
|---|---|---|
| `study_area` | Boundary of the hard-rock study area (2,057 km2) | study_area.shp |
| `geology_units` | Geological units of the study area (1:100,000 mapping; attribute text in Persian) | geology.shp |
